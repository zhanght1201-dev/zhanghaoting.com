## 关于求职

### 前言

今年中秋和国庆，我有一段连放 13 天的假期。换作以前，肯定会非常开心。但因为论文实验和就业的压力，再加上研二可以自己支配的时间增多，感觉放假有些可有可无，也许正是这些压力导致的吧。

当然，假期里还是打了挺长时间的游戏，中途也跑了实验模型，回家过了节。现在到了 10 月，感觉时间更紧了。反正跑模型需要等挺长时间，就在等待的时候开始看看就业准备吧。

今天刷抖音时，经常看到最近秋招的一些个人分享，因为刷视频还是比较轻松。其中很多是计算机专业的分享，更多传递的是焦虑和当前就业市场的困难。我总结下来：一是 AI 发展提高了编码和工作效率；二是目前经济形势不好，整体开发需求下降；三是计算机应届生，或者整个应届生群体的数量，都处于高位。这些因素造成供需不平衡，进一步形成就业压力。

说实话，看得我还是有点焦虑。再想到在职人员的工作强度和裁员风险，也让我有些倾向央国企岗位。之前的就业准备没有坚持下去，感觉自己没有多少熟悉的技术栈，也没有拿得出手的项目。

但大环境和已经过去的事情，不是我能控制的。我只能在自己的能力范围内改变自己，而且又不打算放弃这个行业。这样一来，问题好像又变简单了：大环境和之前的懈怠，只会成为无尽的抱怨点和焦虑来源，也是一种无用功。

这场求职大作战，好像只是看我在剩下的时间里能准备成什么样。至于能不能拿到心仪的 offer，就看缘分和运气了。进一步纠结走哪类企业，也没有太大必要。我估计到时候秋招还是会海投，最后在能获得的 offer 里选择——如果有得选的话。

据此，我和 GPT 讨论并制定了规划，希望能够坚持下去。讨论后的宏观方向还是 Agent 开发，准备思路分为两个方面：一是算法和八股，二是项目和实习。

### 算法和八股

算法和八股的学习，需要日常积累，算是一种计算机基础的准备。

**主线：代码随想录**

它按照数组 → 链表 → 哈希 → 字符串 → 栈队列 → 二叉树 → 回溯 → 贪心 → 动态规划 → 图论的顺序设计，图文和视频配套，很适合从基础重新建立体系。

[代码随想录](https://programmercarl.com/)

**辅助：LeetCode 75**

讨论中提到，它定位于 1～3 个月的面试准备，一共 75 道核心题，可以在后面检查自己是否真正掌握。

[LeetCode 75 中文版](https://leetcode.cn/studyplan/leetcode-75/)

八股主要按计算机网络、操作系统、数据库和 Redis 来准备，主要参考小林 coding；Python 八股单独准备。后续的大模型和 Agent 八股，再结合项目学习。

[小林 coding](https://www.xiaolincoding.com/)

### 项目和实习

这一部分，我的想法是先积累项目，再找实习。主要围绕 Agent 项目，从一个小 demo 开始，通过版本迭代，逐步做成一个较为完整的 Agent 项目。在这个过程中，熟悉 Agent 软件开发和部署的整体流程与框架，再开始投递实习。

本来想通过第一个项目学习开发框架，第二个项目实现自己具体的 Agent 想法，但可能有些拖沓。到时候看情况，或许实习中的项目就是第二个项目。
